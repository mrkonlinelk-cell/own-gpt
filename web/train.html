Train own-gpt

Add text and start a GitHub Actions training run from this phone or PC.

Chat Train

1. Your GitHub token

Keep this private. Use a fine-grained personal access token limited to the own-gpt repository, with Contents: Read and write and Actions: Read and write. Paste it below. It is stored only in this browser’s localStorage — never in the repository or sent anywhere except GitHub’s API when you start a run or refresh status. You can clear it any time, and you should delete the token on GitHub when you no longer need it.

Create a token: GitHub → Fine-grained personal access tokens.

2. Add text and start training

Plain text is enough — no special format required. For better chat replies, you can also write examples as User: and Assistant: lines. Leave the text box empty if you only want to train longer on the current data.

Training runs on GitHub’s free CPU machines (no GPU, max 6 hours). A public repository has unlimited Actions minutes. It will be slow, but it works from your phone. After the run, the chat page updates when the site redeploys.
